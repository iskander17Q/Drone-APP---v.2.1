Этот каталог —  версия приложения с примерами 9 паттернов проектирования.

Структура:
- `design_patterns/`
  - `singleton.py`
  - `factory.py`
  - `builder.py`
  - `adapter.py`
  - `decorator.py`
  - `strategy.py`
  - `observer.py`
  - `command.py`
  - `facade.py`

Каждый модуль реализует класс(ы) и предоставляет `run()`-функцию для
быстрой проверки работоспособности. Для запуска проверки используйте:

`python DesignPatterns/design_patterns/<module>.py`

Модули оформлены для прямого использования в кодовой базе и для
встраивания в тесты. При необходимости можно подготовить набор
unit-тестов или интегрировать конкретные реализации в основную
архитектуру проекта.
